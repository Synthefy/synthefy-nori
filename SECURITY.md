# Security

Report security issues privately by emailing
[support@synthefy.com](mailto:support@synthefy.com) with the subject
**Nori security report**. Do not open a public issue for vulnerabilities or
leaked credentials. Include reproduction details and affected versions, but do
not include secrets or sensitive data unless a maintainer provides a secure
channel.

Checkpoints are loaded with PyTorch and should be treated as trusted artifacts.
Only load checkpoints from sources you control or trust.
